# Backend Lab · 后端实验室

[English](README.md) | [简体中文](README.zh-CN.md)

通过引导式实验学习后端开发：从业务规则出发，跟踪请求经过的处理层，观察数据变化，再练习排查和修复错误。

## 开始使用

直接用现代浏览器打开 **`index.html`**。无需安装依赖、注册账户、配置密钥或启动真实的服务器和数据库，也没有构建步骤。

也可以在项目目录启动本地静态服务：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

当前学习界面为简体中文，仓库同时提供英文与中文说明。

## 学习内容

- **理念与职责**：业务规则、输入契约、身份、权限、数据归属和可靠结果。
- **请求流程**：逐步观察八个阶段，比较六种成功与失败场景。
- **代码与数据结构**：了解接口入口、数据结构、认证、业务服务、数据访问和测试的分工。
- **动手实验**：六步 API 带练，配合五个待办接口挑战。
- **排错实验室**：十个案件，覆盖字段校验、凭证过期、路由、权限、数据库连接、异常、超时、重复请求、并发和缓存陈旧。
- **深入学习**：八个专题，细讲契约、授权、事务、可观测性、查询性能、幂等、并发和缓存。

**开发工具箱**独立放置 Linux、Shell 和 Git 练习，包括 44 个基础任务，以及以下十类场景的 74 步实操：

1. 接手陌生项目，定位目录和代码。
2. 筛选、统计并保存错误日志。
3. 备份、修改、载入和回滚配置。
4. 排查脚本执行权限不足。
5. 启动、检查和停止服务。
6. 排查端口不一致，区分连接失败与 HTTP 错误。
7. 打包、检查归档、恢复并验证内容。
8. 编写检查脚本，保存报告，查看命令历史。
9. 定位离线旧日志的空间占用并验证处理结果。
10. 排序、分组、统计重复事件并生成报告。

## 怎样跟着学

第一遍默认直接展示完整命令，并填入模拟终端。点击 **「按示范执行」**，观察结果，通过验收后进入下一步。第二遍可以切换到自己输入，完整示范仍会保留。

例如，要输出一段文字，输入的是：

```sh
echo "hello backend"
```

`hello backend` 是输出内容，不能单独当作命令。终端提示符和 `$` 也不用输入。

排错按固定流程推进：复现 → 查证据 → 提假设 → 修改一个因素 → 重跑 → 回归验证。仅让当前请求成功并不算修好；关闭权限检查等方案会被对应的负向用例拦住。

## 模拟范围

终端命令、服务、API、数据库、执行计划、耗时、锁、归档和缓存都在浏览器里使用教学模型运行，不会执行电脑上的命令，也不会连接真实服务。支持的是页面列出的命令子集，不是完整的 Linux 或 Bash。

每次排错重跑都从相同案件快照开始。切换或重练命令行课程会重置对应虚拟工作区。完成记录与排错笔记保存在浏览器的 `localStorage` 中，清理浏览器数据会删除这些记录。基础待办 API 的内存数据在刷新后恢复。

图示和伪代码用于解释设计，不能直接作为生产后端。模型中的验证也不能证明真实系统的安全、性能或并发正确性。

## 项目结构

```text
backend-lab/
├── index.html             可独立运行的完整学习网页
├── README.md              英文说明
├── README.zh-CN.md        中文说明
├── scripts/               校验和测试入口
└── tests/                 浏览器交互验证
```

HTML 将样式、课程与模拟器放在同一个文件中，以便离线打开。后续修改应继续保持后端学习主线与辅助工具箱的分工。

## 验证

需要 Node.js 22 或更新版本，以及已安装的 Chrome 或 Chromium：

```sh
node scripts/check.cjs
node scripts/test.cjs
```

浏览器不在常见位置时，可设置 `CHROME_BIN`。验证覆盖 API、引导课程、74 个场景步骤、请求流程、排错修复与手机布局，无需 npm 依赖。
